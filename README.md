# Helix brand

Logo files for [Helix](https://github.com/helix-bedrock).

| File | Use |
|---|---|
| `helix-avatar.svg` | Profile picture: GitHub org, Discord, social accounts |
| `helix-mark.svg` | Logo alone on a transparent background: README, favicon, docs |
| `helix-wordmark-light.svg` | Logo + name for light backgrounds |
| `helix-wordmark-dark.svg` | Logo + name for dark backgrounds |

GitHub and Discord need PNG avatars. Export `helix-avatar.svg` at 512×512 or
larger.

## Colours

| Name | Hex | Use |
|---|---|---|
| Helix Cyan | `#00ADD8` | Primary (shared with Go's brand colour) |
| Helix Coral | `#FF6B4A` | Accent |
| Night | `#0B1120` | Dark backgrounds |
| Night Light | `#17233D` | Avatar gradient top |
| Ink | `#0F172A` | Text on light backgrounds |
| Slate | `#64748B` | Secondary text |

The wordmark uses Inter Bold (falls back to Segoe UI or Helvetica).

## Usage

- Do not stretch, recolour, rotate or add effects to the logo.
- Leave clear space around it of at least the width of one helix block.
- You may use the logo to refer to Helix (articles, videos, "works with Helix").
  Do not use it in a way that suggests your project is official Helix without
  permission.
